Business Question 12 Slide 20 / 50

Q12: Ranking Patients by Severity via DENSE_RANK()

Portfolio Solution 12: Window ranking on total Y-BOCS score

-- Solution 12: SELECT patient_id, age, gender, (ybocs_score_obsessions + ybocs_score_compulsions) AS total_ybocs, DENSE_RANK() OVER (ORDER BY (ybocs_score_obsessions + ybocs_score_compulsions) DESC) AS severity_rank FROM ocd_patients;
Business Question 13 Slide 21 / 50

Q13: Patients Exceeding Cohort Average Y-BOCS Score

Portfolio Solution 13: Scalar subquery benchmarking

-- Solution 13: SELECT patient_id, age, gender, (ybocs_score_obsessions + ybocs_score_compulsions) AS total_score FROM ocd_patients WHERE (ybocs_score_obsessions + ybocs_score_compulsions) > ( SELECT AVG(ybocs_score_obsessions + ybocs_score_compulsions) FROM ocd_patients );
Business Question 14 Slide 22 / 50

Q14: Cumulative Patient Counts by Diagnosis Year

Portfolio Solution 14: Running totals with window frames

-- Solution 14: WITH yearly_diag AS ( SELECT YEAR(ocd_diagnosis_date) AS diag_year, COUNT(*) AS new_patients FROM ocd_patients GROUP BY YEAR(ocd_diagnosis_date) ) SELECT diag_year, new_patients, SUM(new_patients) OVER ( ORDER BY diag_year ASC ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW ) AS cumulative_patients FROM yearly_diag;
Business Question 15 Slide 23 / 50

Q15: Categorizing Patient Severity via CASE WHEN

Portfolio Solution 15: Clinical classification tiers

-- Solution 15: SELECT patient_id, (ybocs_score_obsessions + ybocs_score_compulsions) AS total_ybocs, CASE WHEN (ybocs_score_obsessions + ybocs_score_compulsions) > 30 THEN 'Severe' WHEN (ybocs_score_obsessions + ybocs_score_compulsions) >= 20 THEN 'Moderate' ELSE 'Mild' END AS clinical_severity FROM ocd_patients;
